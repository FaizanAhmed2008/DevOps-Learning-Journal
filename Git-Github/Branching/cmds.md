# Git Branching Commands

- List branches: `git branch`
- Create a new branch: `git branch feature-login`
- Switch to a branch: `git switch feature-login`
- Switch to a branch (older command): `git checkout feature-login`
- Switch back to main branch: `git switch main`
- Delete a local branch: `git branch -d feature-login`
- List all branches, local and remote: `git branch -a`
