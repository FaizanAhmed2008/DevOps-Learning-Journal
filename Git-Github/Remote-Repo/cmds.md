# Git Remote Repository Commands

- Add a remote repository: `git remote add origin https://github.com/user/repo.git`
- Check configured remotes: `git remote -v`
- Push the main branch to origin and set upstream: `git push -u origin main`
- Pull changes from origin main: `git pull origin main`
- Fetch updates from origin: `git fetch origin`
- Clone a repository: `git clone https://github.com/user/repo.git`
