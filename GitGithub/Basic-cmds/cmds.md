# Git Basic Commands

- Initialize a new Git repository: `git init`
- Show the current repository status: `git status`
- Stage all changed files: `git add .`
- Stage a single file: `git add file.txt`
- Commit staged changes with a message: `git commit -m "Initial commit"`
- Display the commit history: `git log`
- Show condensed commit history: `git log --oneline`
- Show unstaged changes: `git diff`
- Show commit details or object contents: `git show`
- Remove a file and stage the deletion: `git rm file.txt`
- Rename or move a file and stage the change: `git mv old.txt new.txt`
