# What is Fork?

## Definition
A **fork** is a complete copy of a repository under your GitHub account. You get full control while the original repo remains unchanged.

## Key Differences

**Fork vs Clone:**
| Fork | Clone |
|------|-------|
| Copy on GitHub | Copy on your computer |
| Your own repo | References original |
| For contributions | For local work |
| Takes ~1 minute | Instant |

## Why Fork?

✅ **Contribute** - Add features/fix bugs without write access
✅ **Experiment** - Try changes safely
✅ **Learn** - Study and modify code
✅ **Maintain** - Keep your version updated
✅ **Preserve** - Archive if original project dies

## Visual Flow
```
Original Repo (upstream)
        ↓
    You Click "Fork"
        ↓
Your Fork (origin) → Clone to Computer → Make Changes → Push to Your Fork → Create PR
```
