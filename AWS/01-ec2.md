# AWS EC2 (Elastic Compute Cloud)

## Key Concepts
- **EC2**: Virtual servers (instances) hosted on Amazon Web Services infrastructure.
- **AMI (Amazon Machine Image)**: Pre-configured template containing OS and initial setup.
- **Instance Type**: Defines hardware specs like vCPU, RAM, and network performance (e.g., `t2.micro`).
- **Key Pair**: Secure SSH key pair (`.pem` file) used to log into Linux instances.
- **Security Group**: Virtual firewall controlling inbound and outbound traffic rules.
- **EBS (Elastic Block Store)**: Persistent block storage volume attached to the instance.

## Commands (AWS CLI)
- List running instances:
  - `aws ec2 describe-instances`
- Launch a new instance:
  - `aws ec2 run-instances --image-id <ami-id> --instance-type t2.micro --key-name <key-name>`
- Start an instance:
  - `aws ec2 start-instances --instance-ids <instance-id>`
- Stop an instance:
  - `aws ec2 stop-instances --instance-ids <instance-id>`
- Terminate an instance:
  - `aws ec2 terminate-instances --instance-ids <instance-id>`

## Notes
- **Pay-as-you-go**: You pay only for compute time when instances are running.
- **Elastic IP**: Static IPv4 address that remains constant across restarts.
- **Auto Scaling**: Automatically adds or removes instances based on traffic load.
